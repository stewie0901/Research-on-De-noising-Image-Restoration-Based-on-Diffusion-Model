# DDPM-based Image Restoration

This project is an implementation and exploration of a **Denoising Diffusion Probabilistic Model (DDPM)** for image restoration and generation.

The project uses cat images from the **CIFAR-10 dataset** and implements the diffusion process, neural network architecture, training procedure, and reverse denoising process in PyTorch.

Rather than focusing only on the final image quality, this project was also used to explore the connection between **probability models and generative deep learning**, particularly how Gaussian noise and probabilistic diffusion processes can be applied to image generation.

## Project Overview

A diffusion model gradually adds noise to an image through a forward diffusion process and learns to reverse this process through denoising.

In this implementation, the forward process follows:

```math
x_t = \sqrt{\bar{\alpha}_t}x_0 + \sqrt{1-\bar{\alpha}_t}\epsilon
```

where

```math
\epsilon \sim \mathcal{N}(0,I)
```

Therefore, the noisy image at each timestep can be viewed as a sample generated by introducing Gaussian random noise according to a predefined noise schedule.

During training, the neural network receives the noisy image $x_t$ and timestep $t$, and learns to estimate the noise that was added. The learned model is then used in the reverse diffusion process to progressively recover an image from noise.

## Probability Concepts

This project provided a practical way to revisit several probability-related concepts:

- **Gaussian distribution** — random Gaussian noise is introduced during the forward diffusion process.
- **Random variables and sampling** — both diffusion timesteps and noise are sampled during training.
- **Conditional distributions** — the reverse diffusion process models the transition from a noisy state toward a less noisy state conditioned on the current state.
- **Variance / noise scheduling** — the beta schedule controls the amount of noise introduced throughout the diffusion process.
- **Probabilistic generative modeling** — image generation is formulated as a sequence of stochastic diffusion and denoising steps.

These concepts helped connect probability theory with an actual machine-learning implementation rather than treating them only as mathematical definitions.

## Implementation

### Dataset

The experiment uses the **cat class (label 3) from CIFAR-10**.

Images are resized to **64 × 64**.

### Diffusion Process

The implementation supports both linear and cosine beta schedules. The current experiment uses a **Cosine Beta Schedule** with:

- **T = 1000 diffusion steps**

The cumulative product

$$
\bar{\alpha}_t = \prod_{s=1}^{t}(1-\beta_s)
$$

is used to generate noisy samples at arbitrary timesteps.

### Neural Network

The denoising network is a custom UNet-like architecture containing:

- Convolutional encoder and decoder blocks
- Skip connections
- Time-step embedding
- MLP-based time conditioning
- Group normalization
- SiLU activation

The timestep information is embedded and incorporated into the network so that the model can learn different denoising behavior at different stages of the diffusion process.

### Training

Main training configuration:

| Parameter | Value |
| --- | --- |
| Dataset | CIFAR-10 (Cat class) |
| Image size | 64 × 64 |
| Diffusion steps | 1000 |
| Beta schedule | Cosine |
| Batch size | 32 |
| Epochs | 200 |
| Optimizer | AdamW |
| Learning rate | 2e-4 |
| Weight decay | 1e-4 |
| Loss | Mean Squared Error |
| EMA decay | 0.9999 |

During each training iteration:

1. An original image $x_0$ is selected.
2. A random timestep $t$ is sampled.
3. Gaussian noise is added according to the diffusion schedule.
4. The model predicts the noise contained in $x_t$.
5. MSE is calculated between the predicted and actual noise.
6. Model parameters are updated through backpropagation.

Gradient clipping is also applied to improve training stability.

## Exponential Moving Average (EMA)

An Exponential Moving Average of model parameters is maintained during training.

The EMA weights are used during sample generation to reduce instability caused by short-term parameter fluctuations and improve the consistency of generated results.

## Training and Checkpointing

The training script supports:

- Automatic checkpoint saving
- Training loss recording
- Automatic training resumption
- Periodic sample generation
- EMA weight saving and restoration

This made it possible to continue longer experiments without restarting training from the beginning.

## Image Restoration Experiment

In addition to generating images from random noise, the project tests the denoising process on an existing CIFAR-10 cat image.

A clean image $x_0$ is first corrupted to timestep **t = 200**.

The model then performs the reverse process step by step from **t = 200** to **t = 0**.

Intermediate images are recorded to visualize how the model progressively removes noise.

The current results show that the model is able to recover recognizable image structure from a moderately noisy input, although the reconstruction quality remains limited and there is still room for further improvement.

## Training Result

The training loss decreases substantially during the early epochs and later stabilizes around approximately **0.012**.

This suggests that the model learns the noise-prediction objective, although a low training loss does not by itself guarantee high-quality generated images.

## Limitations

This is an exploratory implementation rather than a mature generative model.

Current limitations include:

- CIFAR-10 provides relatively low-resolution source images.
- The experiment only uses the cat subset of the dataset.
- Generated and restored images remain blurry in some cases.
- Model architecture and hyperparameters have not been systematically optimized.
- Image quality has not yet been evaluated using quantitative generative-model metrics.

Future improvements could include experimenting with different network architectures, noise schedules, training settings, datasets, and quantitative evaluation methods.

## Purpose

This project began as an exploration of diffusion-based image restoration and generative modeling.

Through implementing the forward and reverse diffusion processes, it also became a practical exercise in understanding how probability concepts—especially Gaussian noise, random sampling, probability distributions, and stochastic processes—appear in modern machine-learning models.

The current model is still experimental, but the implementation process provided experience in connecting mathematical concepts with model design, training, experimentation, and evaluation.
